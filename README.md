## ✨ Features

* **Glassmorphic UI:** Stunning iOS-style design with advanced background blur and transparency controls.
* **Massive Library:** Integrated with the TMDB API to fetch thousands of trending, classic, and retro movies, series, and anime.
* **Smart Profiles:** Create multiple user profiles with optional PIN protection or instant password-free access.
* **Advanced Customization:** Dynamic theme colors, background image URL support, opacity/darkness sliders, and text scaling options.
* **Smooth Hero Banner:** Slow-transitioning featured banner highlighting top trending titles with ratings and overviews.
* **Watchlist & History:** Personal "Watchlist" and "Continue Watching" tracker with custom media status toggles.
* **Multi-Server Video Player:** Fast and reliable streaming integration (VidSrc & AutoEmbed) with intuitive season/episode selectors.
* **Interactive Reviews:** Star ratings, comments, site-wide average rating calculator, and secure comment deletion.
* **Multi-Language Support:** Fully supports Arabic, English, French, and German with automatic RTL/LTR switching.
